# AI CRYPTO RADAR V3.5

هذه النسخة تجمع بين:
- فحص Spot USDT الواسع.
- Multi-Timeframe accumulation.
- Real-time Binance WebSocket aggTrade لطبقة Order Flow التكيفية.
- Volume Profile من الصفقات الحالية، وKline-based historical profile للتاريخ.
- V3.1: اختبار تاريخي تلقائي لأفضل 30–50 عملة وترتيب التركيبات الناجحة.

## فلسفة المشروع
الهدف هو اكتشاف مراحل ACCUMULATION / READY قبل الحركة الكبيرة، وليس مطاردة العملات بعد الانفجار. لا توجد خوارزمية تضمن "الوصول إلى القمر"؛ النتائج احتمالية ويجب قياسها تاريخيًا.

## WebSocket
الطبقة الحية تراقب افتراضيًا أفضل 120 رمزًا مؤهلًا من حيث السيولة، بينما الفحص الأساسي يبقى واسعًا على كامل الكون المؤهل. لا توجد مفاتيح API ولا تداول آلي.

## Backtest
زر "اختبر أفضل 50" يختبر أفضل العملات الحالية على 30 يومًا من 15m. النتائج تتضمن Win Rate، متوسط العائد، MFE، وعدة تركيبات: ACC+FLOW+VP، ACC+FLOW، ACC+VP، FLOW+VP، EARLY_COMPRESSION.
